# cursor-leaderboard

Weekly Cursor usage leaderboard generated by a scheduled GitHub Action and served on a TV via GitHub Pages.

## Live face-detection overlay

The same TV page also supports a realtime "LIVE" detection card driven by a FastAPI backend and a camera-equipped phone. See [`docs/face-detection.md`](docs/face-detection.md) for the design, and [`backend/README.md`](backend/README.md) for run instructions. The overlay is a no-op when the backend is unreachable, so the weekly leaderboard keeps working unchanged.
