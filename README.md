# cursor-leaderboard

Weekly Cursor usage leaderboard generated by a scheduled GitHub Action and served on a TV via GitHub Pages. An optional realtime layer uses a phone camera and FastAPI to show live detection cards on the same TV display.

## What it does

1. **Weekly batch** — Scrapes Cursor Analytics (Playwright), merges employee data, scores usage + prompt quality, and generates a static HTML Top-10 slideshow.
2. **TV display** — Full-screen carousel auto-deployed to GitHub Pages (`docs/index.html`).
3. **Live overlay (optional)** — Phone captures faces → FastAPI recognizes them → WebSocket pushes a 10-second live card to the TV.

## Quick start

```bash
# Install
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && playwright install chromium

# Configure (see docs/configuration.md)
export HUB_API_KEY=...
export DAILY_ACTIVITY_API_KEY=...

# Run pipeline (requires state_fixed.json)
python src/pipeline.py

# View leaderboard
open output/latest/leaderboard.html
```

For live face detection, see [docs/getting-started.md](docs/getting-started.md).

## Project structure

```
src/           Batch pipeline (download, merge, analyze, generate)
backend/       FastAPI realtime service (face detect + WebSocket)
frontend/      Phone camera page
data/          Raw/processed CSVs and face reference photos
output/        Generated leaderboard HTML
docs/          GitHub Pages + documentation
```

## Tech stack

- **Pipeline:** Python 3.11, pandas, Playwright, requests
- **Backend:** FastAPI, uvicorn, face_recognition (dlib)
- **Frontend:** Vanilla HTML/CSS/JS (no build step)
- **Storage:** CSV files (no database)
- **CI/CD:** GitHub Actions → GitHub Pages

## Live overlay

The TV page connects to a WebSocket when a backend is running. If the backend is unreachable, the weekly slideshow continues unchanged.

```
Phone  →  POST /detect  →  FastAPI  →  WS /ws  →  TV browser
```

Open the TV with a WebSocket URL:

```
output/latest/leaderboard.html?ws=ws://localhost:8000/ws
```

See [docs/face-detection.md](docs/face-detection.md) for HTTPS requirements on real phones.

## CI

GitHub Actions runs every **Monday 10:00 UTC** (`.github/workflows/pipeline.yml`).

Required secrets: `HUB_API_KEY`, `DAILY_ACTIVITY_API_KEY`, `CURSOR_STATE`.
